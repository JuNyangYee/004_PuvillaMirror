# 갤러리 유화 업데이트

Paseo의 “Analyze kit and filter gallery structure” 세션과 nau-filter-viewer를 참고했다. 참고 앱은 ThrowSnow에 일부 GLSL만 이식하고 기존 수치를 유지한다. 이 프로젝트는 공식 독립 모듈을 통째로 받고, 갤러리 페이지에서 유화 조절 스키마까지 함께 추출한다.

- 엔진: https://nau-filter-gallery.vercel.app/nau-filter/nau-filter.js
- 조절 항목·범위: https://nau-filter-gallery.vercel.app/
- 최초 포함판: b1325c7 (2026-11-03). 현재 내장 복구본: 7f58eaa (2026-11-05).
- 기본: 필터 세기 50, 그림체 평면, 획 다시 놓기 0.02, 15fps, 색 보정 1. 내부 강도 0.29 / 붓 크기 1.23. 세부 보존 문턱 0.10, 눈·코 테 정리 1.
- 최초 16개 조절 항목: 그림체, 필터 세기, 획 다시 놓기, fps, 색 보정, 붓 굵기 3개, 획 길이, 획 색 흔들림, 요철, 광택, 캔버스 결, 세부 보존 문턱, 눈·코 테 정리, 흰색 지키기.
- 강도와 크기는 현재 갤러리처럼 필터 세기가 함께 조절한다. 개별 세부 조절은 그 위에 덮어쓴다.
- 마스크가 필요한 캐릭터 노말은 꺼져 있다. 추가 마스크 패스 없이 장면 전체에 유화를 입힌다. 갤러리 웹 UI의 색 톤은 독립 모듈 API가 지원하지 않아 가져오지 않는다. 비교 위치·해상도는 앱 자체 출력 설정이다.

## 사용

D → 유화 필터 업데이트 → 최신판 확인 → 시험 렌더 후 적용 → 새로고침.
팔레트 버튼에서 내려받은 조절 항목과 값을 변경한다. 숫자 입력칸은 1.23, 0.096처럼 슬라이더 간격에 맞지 않는 갤러리 기본값도 그대로 표시한다.
업데이트 적용 시 새 판의 기본값을 사용한다. 이전 판 튜닝은 config의 gallery.history에 보관하며, 해당 판으로 돌아오면 복원한다. 같은 판을 다시 적용해도 사용자 튜닝은 유지한다.
이전 판 목록에서 GPU 시험 후 복원할 수 있다.

## 저장과 배포

public/filter/current.json은 엔진 원문, SHA-256, 스키마, 기본값, 세기 곡선을 하나로 저장한다. 엔진과 UI가 서로 다른 버전으로 적용되지 않는다.
교체 전 패키지는 public/filter/history에 남긴다. 후보는 서버 메모리에 있으며 서버를 재시작하면 다시 확인해야 한다.
개발 서버와 vite preview, 새 portable 패키지의 로컬 서버가 API를 지원한다. API는 루프백·동일 출처에서만 변경을 허용한다.
일반 정적 호스팅과 단일 HTML에서는 포함된 판을 오프라인으로 사용하고, 웹 UI 업데이트는 로컬 서버에서 수행해야 한다. 단일 HTML에도 현재 패키지가 포함된다.
src/vendor/gallery-bundle.json은 네트워크/파일 손상 때 사용할 내장 검증판이다. 이전 oil-stroke.js도 Git과 vendor에 남아 있다.
공용 설정·미디어·모델 파일은 업데이트 API가 변경하지 않는다.

## 검증과 한계

서버는 내려받은 JavaScript를 실행하지 않는다. 데이터 리터럴만 해석하고, 페이지와 모듈의 유화 프리셋·세기 곡선이 일치하는지 확인한다. 숫자 조절 항목의 추가/범위/간격/기본값 변경은 UI에 반영된다.
지원하지 않는 API/표현식/조절 타입으로 바뀌면 기존 판을 유지하며 오류를 표시한다. 임의의 미래 코드 변경을 모두 호환한다는 뜻은 아니다.
브라우저는 해시를 확인한 뒤 공식 출처의 모듈을 로드하고, 별도 작은 WebGL 캔버스로 컴파일·렌더·빈 화면·조절 경로를 시험한다. 해시는 공식 서명이 아닌 파일 일관성 검사다.
시작할 때 현재 판이 실패하면 내장판으로 돌아간다. 업데이트는 버튼을 누를 때만 확인한다.
렌더는 기존 PaintCadence를 사용한다. MediaPipe/YOLO/캐릭터 보간은 변경하지 않는다. 갤러리 15fps 기본값은 이전 12fps보다 더 자주 원본 장면을 그린다.

검사: npm run filter:check, npm run build, npm run pipeline:check, npm run presentation:check.

## 2026-11-06 재점검

현재 공식 배포판 7f58eaa를 기존 가져오기 코드가 그대로 읽는다. 엔진 일부를 이식하는 참고 앱과 달리 독립 모듈 전체와 페이지 스키마를 받으므로 새 GLSL 구간에도 별도 이식 수정이 필요하지 않았다. 현재 조절 항목은 20개이며 OIL.edge / spill / slope 기본 1, halo 기본 0이 추가됐다. 실제 렌더에서 네 값 각각의 영향과 GL 오류 없음을 확인했다.

이전 검사는 운영자가 갱신하는 current.json을 11/03 HTML과 비교해 최신판에서도 실패했다. 이제 11/03·11/05 실물 자료를 고정 회귀 입력으로 사용하며 운영 파일은 무결성을 별도로 검사한다. 11/03→11/05 적용과 이전판 복원도 검사한다. GPU 적용 검사는 기본값 수용뿐 아니라 다른 수치로 변경되는지와 변경 후 렌더까지 확인한다.

npm run filter:check:live는 실행 시 공식 서버를 다시 받아 현재 적용판·내장판과 비교하고 추가/변경/삭제된 조절 항목을 출력한다. 저장된 파일을 바꾸지는 않는다.
