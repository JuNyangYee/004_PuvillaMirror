# 파라미터 창 안내

[README](../README.md) · [운영·단축키](OPERATOR_GUIDE.md) · [개발·빌드](DEVELOPMENT.md)

`D` 또는 톱니바퀴 버튼으로 **푸빌라 설정**을 엽니다. 유화 세부 조절은 별도의 팔레트 버튼에 있습니다. 아래 이름은 현재 `src/overlay.ts`, `src/cameraPreview.ts`, `src/galleryControls.ts` 기준이며, 실제 배포값은 [public/config.json](../public/config.json)을 확인합니다. 코드 기본값과 현장 튜닝값은 다를 수 있습니다.

숫자의 `ms`는 밀리초, `°`는 도, `rad`는 라디안, `×`는 배율입니다. 비율 0.05는 5%입니다. 표시된 범위 안에서 한 항목씩 바꾸고 실제 참여 거리에서 확인합니다.

## 설정 저장과 재시작

| 환경 | 저장 위치·동작 |
| --- | --- |
| `npm run dev` | 조절 완료 후 약 0.4초 뒤 `public/config.json`에 저장 요청 |
| 빌드·미리보기·Portable·단일 HTML | 해당 브라우저·주소의 localStorage에 배포 설정과의 차이를 저장 |
| 저장 실패 시 | **지금 저장 (config.json)**을 누르면 파일 다운로드로 대체 |

**지금 저장**은 항상 다운로드하는 버튼이 아닙니다. 먼저 환경에 맞는 저장을 시도합니다. 빌드 화면의 저장 성공 토스트가 `public/config.json`을 언급하더라도 실제 저장 위치는 localStorage입니다. 다른 PC·브라우저·주소에는 자동 전달되지 않습니다.

개발 서버 저장은 화면 시점 관련 값을 파일 로딩 당시 값으로 보존합니다. 대상은 `scene.cameraYawDeg`, `cameraTiltDeg`, `layout`, `outputMirror`, `viewCenterCm`, `viewHeightCm`, `viewOffsetXcm`, `pViewCenterCm`, `pViewHeightCm`, `pViewOffsetXcm`입니다. 드래그·휠·출력 반전으로 조정한 구도를 공용 기본값으로 배포하려면 **시점 값 복사**로 값을 확인하고 `public/config.json`을 직접 수정한 뒤 빌드합니다. 다운로드 대체 경로는 현재 메모리의 시점값도 포함합니다.

빌드 화면은 위 시점값도 브라우저 설정에 포함할 수 있습니다. 새 공용 설정이 일부 반영되지 않는다면 해당 사이트의 기존 localStorage 덮어쓰기 여부를 확인합니다. 설정 키는 `pubilla-mimic-config-v2`, 툴바 숨김 키는 `puvilla.controlsHidden`입니다.

**재시작**은 페이지 새로고침입니다. 항목 이름에 재시작이 명시된 경우 저장 후 누릅니다. 개발 서버에서 저장한 공용값을 전시 빌드에 반영하려면 다시 빌드·배포해야 합니다.

## 인식 설정 — YOLO · MediaPipe

설정 경로는 `person`, `recognition`입니다.

| 항목 | 설명·조정 효과 |
| --- | --- |
| YOLO로 대상 1명 선택 | 사람 검출 기반 대상 선택 사용 |
| 사람 검출 신뢰도 | 0.15~0.9. 높이면 낮은 신뢰도의 사람 후보를 제외 |
| YOLO 검출 간격 | 50~500ms. 늘리면 검출 빈도가 낮아짐 |
| 입력 박스 여백 | 0.05~0.5. 선택한 사람의 입력 영역에 추가할 여백 |
| 전환할 사람의 최소 크기 배율 | 1~2배. 현재 대상보다 얼마나 커야 전환 후보가 되는지 |
| 더 큰 사람으로 전환 대기 | 0~5000ms. 대상이 자주 바뀔 때 전환 대기 조절 |
| 사람 박스 소실 유예 | 200~1000ms. 검출이 잠깐 끊겼을 때의 유예 |
| 얼굴 연속 확인 후 시작 | 150~1500ms. 얼굴을 연속 확인하고 따라하기를 시작하기까지의 기준 |
| YOLO 다시 초기화 | 사람 검출기를 다시 초기화 |

**참여 범위 · 단계** 하위 폴더:

| 항목 | 설명 |
| --- | --- |
| 좌·우·상·하 제외 마진 | 각 0~0.45. 카메라 화면 가장자리에서 제외할 비율. 미리보기 드래그로도 조절 |
| 1 준비: 사람 면적 ≥ | 0.005~0.5. 인식 준비 단계의 사람 면적 기준 |
| 2 인식: 사람 면적 ≥ | 0.01~0.8. 실제 인식 단계의 사람 면적 기준 |
| 2 인식: 얼굴 높이 ≥ | 0.02~0.5. 얼굴 높이 비율 기준 |
| 준비 고개 회전 | 0~35°. 준비 단계의 두리번거림 크기 |

면적·높이 값은 실제 거리 단위가 아닙니다. 카메라 화각·배치에 따라 현장에서 조절합니다.

## 떨림 보정 — 부드러움 vs 반응속도

`smoothing`의 **고개 부드러움 / 고개 빠른 동작 반응**, **표정 부드러움 / 표정 빠른 변화 반응**, **눈 깜빡임 반응**을 조절합니다. 부드러움 항목의 cutoff는 작을수록 매끄럽지만 지연이 늘고, 빠른 동작 반응의 beta는 클수록 변화에 빨리 반응합니다. 눈 깜빡임 반응은 클수록 빠릅니다.

## 합성 윤곽 — 고급

**털 끝 투명도 하한 / 상한**(`filter.edgeLo`, `edgeHi`)은 합성 윤곽 조절값입니다. 현재 전시 구성은 `presentation.ts`에서 기존 `filter.enabled`를 끄므로, 모든 구형 합성 옵션이 현재 유화 결과에 적용된다고 가정하지 마세요. 유화 사용 스위치는 별도의 `filter.oil.enabled`입니다.

## 조명 — 밝기·위치

**전체 밝기(노출)**는 장면 노출값입니다. 실제 카메라 영상의 노출과 별개입니다.

**주광**, **보조광**, **테두리광**, **눈밭 반사광** 폴더에는 각각 밝기, 겨울 배경 색상, 좌우 위치, 높이 각도가 있습니다. 정면 구도 기준 좌우 0°는 앞, -90°는 왼쪽, +90°는 오른쪽, ±180°는 뒤이며 높이 90°는 머리 위입니다.

**주변광**은 그림자 쪽 밝기, **하늘 반사색 / 눈밭 반사색**은 주변 색, **환경 반사**는 환경광 반응을 조절합니다. **조명 위치 초기화**는 방향을 초기화하며 밝기·색 전체를 초기화하는 기능이 아닙니다.

| 얼굴 추론 장치 | GPU / CPU 선택 |
| 얼굴 추론 간격 / 상반신 추론 간격 | 1~4프레임. 늘리면 추론 빈도 감소 |

입력 회전 외의 초기화 관련 항목은 저장 후 재시작하여 확인합니다.

## 카메라 미리보기의 노출 조절

미리보기 아래 **카메라 노출 조절 보이기**로 엽니다. 장치가 지원하는 항목만 표시됩니다.

- **자동 노출**: 끄면 노출 시간, 켜면 노출 보정을 조절합니다.
- **노출 시간**: 지원 장치의 단계에 맞춰 조절합니다.
- **노출 보정 / 밝기 / 대비**: 카메라 입력 영상에 적용합니다.
- **숨기기**: 조절 영역만 접으며 숨김 상태는 `camera.controlsHidden`에 저장합니다.

범위와 지원 여부는 카메라에 따라 달라집니다. 이 조절은 3D 장면 조명의 전체 밝기와 별개입니다.

## 팔레트 — 유화 조절

**유화 필터 사용**을 켜고 적용 패키지의 버전·날짜를 확인합니다. 항목과 범위는 `public/filter/current.json`의 스키마에서 생성되므로 업데이트 후 바뀔 수 있습니다.

| 항목 묶음 | 역할 |
| --- | --- |
| 필터 세기 / 소스 그림체 | 전체 효과 강도와 평면·3D 입력 해석 |
| 쇼 유화 버전 | 해당 패키지의 유화 프리셋 선택. 변경하면 세부 튜닝과 획 다시 놓기 오버라이드 초기화 |
| 획 다시 놓기 / 초당 그림 | 획 배치 변화와 유화 갱신 빈도. 카메라 추론 fps와 별개 |
| 색 보정 / 흰색 지키기 | 색 처리 강도와 밝은 무채색 보존 |
| 굵은·중간·가는 붓 굵기 / 획 길이 | 붓 형태와 길이 |
| 획 색 흔들림 / 캔버스 결 | 획별 색 변화와 바탕 질감 |
| 물감 요철 / 광택 | 물감 표면의 입체감과 반사 |
| 세부 보존 문턱 | 원본과 다른 세부를 가는 붓으로 보완하는 기준 |
| 눈·코 테 정리 / 남색 눈 판정 | 작은 어두운 눈·코 둘레의 번짐 처리 |
| 경계 밖 잔획 / 경계 옆 번짐 띠 / 경계 둘레 테 정리 | 경계 주변에 남는 획·번짐·테 보정 |
| 그늘 띠 붓 방향 / 붓 방향 시간 평활 | 그라데이션을 따르는 방향과 프레임 사이 방향 안정화 |
| 층 높이 오프셋 / 획 옆 둑 / 홈 그늘 / 바니시 광택 | 칠의 층·가장자리·홈·넓은 광택 표현 |
| 결 크기 | 붓결의 상대 크기 |
| 비교 위치 | 원본과 필터 결과를 나누어 비교할 위치 |
| 처리 해상도 | ½ / ¾ / 1. 낮추면 처리 부하를 줄일 수 있음 |
| 쇼 첫 화면 기본값으로 | 현재 패키지의 기본 조절값으로 복원 |

숫자 입력칸으로 세밀하게 입력할 수 있으며, 항목에 마우스를 올리면 패키지에 포함된 도움말을 확인할 수 있습니다. 결 크기는 표현 크기, 처리 해상도는 렌더 비용에 관계된 별도 설정입니다.

## 유화 필터 업데이트

`D` → **유화 필터 업데이트**에서 **최신판 확인 → 시험 렌더 후 적용 → 새로고침해서 반영** 순으로 실행합니다. **이전 판 목록**은 저장된 패키지를 시험 렌더한 뒤 복원합니다.

개발·미리보기·Portable의 지원 로컬 서버에서 사용합니다. 일반 정적 호스팅과 단일 HTML은 포함된 필터를 사용하며 업데이트 API가 없습니다. 서버 저장판과 현재 화면 적용판은 새로고침 전까지 다를 수 있습니다. 패키지·튜닝 보존 및 복구 방식은 [유화 업데이트 문서](FILTER_UPDATES.md)를 참고합니다.
