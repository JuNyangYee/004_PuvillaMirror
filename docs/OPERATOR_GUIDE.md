# 운영 가이드와 단축키

[README](../README.md) · [파라미터 창](PARAMETERS.md) · [개발·빌드](DEVELOPMENT.md)

현재 `src/main.ts`, `src/viewControls.ts`, `src/overlay.ts`, `src/sim.ts` 기준입니다.

## 실행과 현장 조정

1. [설치 순서](../README.md#시작하기)에 따라 개발 서버를 실행하고 카메라 권한을 허용합니다.
2. `D`로 설정을 열어 카메라 미리보기와 인식 상태를 확인합니다. 세로 설치 카메라는 **카메라·트래커 → 카메라 입력 회전**으로 맞춥니다.
3. **카메라 인식 디버그 → 참여 허용 범위 · 단계**를 켜고 참여 영역을 맞춥니다. 미리보기의 가장자리·모서리를 드래그하면 마진, 안쪽을 드래그하면 범위 위치가 바뀝니다.
4. 한 사람이 참여 범위 안에서 정면을 보고 눈을 뜹니다. **고개·표정 매핑 → 화면 보고 눈 뜬 상태로 기준 다시 맞춤**으로 기준을 맞출 수 있습니다.
5. 고개·표정·팔 반응, 사람이 들어오고 나갈 때의 전환을 확인한 뒤 조명·유화를 조정합니다.
6. 저장 방식을 확인하고 재시작 후 설정을 점검합니다. `D`로 디버그 화면을 닫고 `F`로 아이콘을 숨깁니다.

상태 표시는 대기(IDLE), 유도(ATTRACT), 인식 준비(PREPARE), 등장(ENTER), 따라하기(MIMIC), 퇴장(EXIT)입니다. 사람 박스가 보이는 것과 실제 따라하기 시작은 별개이며, 참여 범위·크기·얼굴 연속 확인 조건을 함께 사용합니다.

## 일반 화면 단축키

| 키 | 동작 | 조건·참고 |
| --- | --- | --- |
| `D` | 파라미터 창·통계·카메라 디버그 표시/숨김 | 톱니바퀴 버튼과 동일 |
| `F` | 툴바 아이콘 표시/숨김 | 전체화면 키가 아님. 숨김 상태는 브라우저에 저장 |
| `R` | 화면 시점 초기화 | 회전·줌·이동 초기화. Shift 없이 사용 |
| `Esc` | 유화 조절 패널 닫기 | 브라우저 전체화면 종료 동작도 발생할 수 있음 |
| `T` | 안내형 표정 테스트 시작/닫기 | 개발 서버의 실제 카메라 모드만. 시뮬레이션·키오스크 제외 |

`D/F/R`은 영문 입력 상태에서 사용합니다. 입력칸 편집 중, 한글 조합 중, Ctrl/Meta/Alt와 함께 누를 때는 처리하지 않습니다. `T`와 시뮬레이션 키에는 같은 입력 보호가 없으므로 입력칸 밖에서 짧게 누르세요. `T` 테스트는 표정별 준비 1.5초·유지 4초로 진행하며 수치와 정답 라벨을 `.trace/trace.jsonl`에 기록합니다.

## 화면 버튼

| 버튼 | 기능 |
| --- | --- |
| 전체화면 | 브라우저 전체화면 진입/해제. 미지원 브라우저에서는 비활성화 |
| 팔레트 | 유화 사용, 버전, 효과, 비교 위치, 처리 해상도 조절 |
| 좌우 화살표 | 캐릭터 출력 좌우반전. 카메라 인식 입력 반전과 별개 |
| 산 모양 | 겨울 마을 / 단색 배경 전환 |
| 톱니바퀴 | 설정창 열기/닫기 |

팔레트 밖 클릭 또는 `Esc`로 유화 패널을 닫습니다. 아이콘이 없으면 `F`로 다시 표시합니다. 키오스크는 툴바와 설정창을 생성하지 않으므로 주소에서 `kiosk=1`을 제거하고 다시 열어 조정합니다.

## 마우스·터치

캐릭터 렌더 화면 위에서 조작합니다.

| 조작 | 동작 |
| --- | --- |
| 왼쪽 버튼 드래그 / 한 손가락 드래그 | 시점 좌우·상하 회전 |
| 휠 버튼을 누른 채 드래그 | 화면 좌우·상하 이동 |
| 마우스 휠 | 확대/축소 |
| 두 손가락 벌리기·오므리기 | 확대/축소 |
| 두 손가락 중심 이동 | 화면 이동 |
| `R` | 시점 초기화 |

시점의 영구 반영 방법은 [설정 저장](PARAMETERS.md#설정-저장과-재시작)을 따릅니다.

## 웹캠 없는 시뮬레이션

`http://localhost:5175/?sim=1`은 카메라와 얼굴·포즈 트래커를 생략하고 가상 신호를 만듭니다. 아래 표정·동작 키는 누르는 동안 적용됩니다. 실제 표현은 캐릭터 매핑 설정에 따라 달라집니다.

| 입력 | 가상 신호 |
| --- | --- |
| 마우스 위치 / 휠 | 고개 좌우·상하 / 갸웃 |
| `S` / `O` / `P` | 웃음 / 입 벌림 / 입 오므림 |
| `B` / `L` / `R` | 양눈 감기 / 왼눈 감기 / 오른눈 감기 |
| `F` / `U` / `A` / `C` | 찡그림 / 눈썹 올림 / 눈썹 내림 / 볼 부풀림 |
| `1` / `2` | 캐릭터 왼팔 / 오른팔 들기 |
| `3` / `4` / `5` | 만세 / 손 흔들기 / 팔 앞으로 |
| `Q` / `E` | 몸 기울이기 |
| `Z` / `X` | 몸 비틀기 |
| `N` | 사람 있음/없음 토글 |
| `0` | 상반신 신호 켜기/끄기 토글 |

일반 조작도 동시에 동작합니다. `F`는 아이콘도 숨기고, `R`은 시점도 초기화하며, 렌더 화면 위 휠은 줌도 바꿉니다. `N/0`은 길게 누르면 키 반복으로 여러 번 전환될 수 있습니다. 팔·눈의 좌우는 출력 반전과 시점에 따라 화면 방향이 달라집니다.

자동 동작은 `?sim=1&armdemo=1`(팔 동작 순환), `?sim=1&armdemo=wave`(손 흔들기)로 확인합니다.

## 실행 옵션

| URL 옵션 | 용도 |
| --- | --- |
| `?sim=1` | 웹캠 없는 시뮬레이션 |
| `?kiosk=1` | 설정 UI 없는 전시 모드. 설정에 따른 커서 숨김·절전 방지 요청·치명 오류 후 재시작 |
| `?debug=1` | 터치 기기의 디버그 표시 분기 해제. 설정창은 `D` 또는 톱니바퀴로 열기 |
| `?quality=max` | 최고 품질 고정, 자동 하향 해제 |
| `?quality=0` ~ `?quality=5` | 품질 단계 고정. 0이 가장 높고 5가 가장 낮음 |

여러 옵션은 `?sim=1&quality=0`처럼 연결합니다. 키오스크 URL 자체가 브라우저 전체화면 실행을 보장하지는 않습니다.

## 문제 해결

| 증상 | 확인 순서 |
| --- | --- |
| 카메라가 열리지 않음 | 카메라 권한, 장치 연결, 다른 앱의 점유, localhost 또는 HTTPS 접속 여부 |
| 모델 로딩 실패 | `npm run fetch-models`, `npm ci`의 WASM 복사 결과, 네트워크 |
| 사람 박스는 있는데 따라하지 않음 | 참여 마진, 사람 면적·얼굴 높이 기준, 얼굴 연속 확인, 조명 |
| 팔만 움직이지 않음 | 상반신 추적·미믹 켜짐과 재시작 여부, 포즈 모델 로딩, 어깨·팔의 화면 내 노출 |
| 눈이 계속 감기거나 고개가 치우침 | 정면·뜬 눈 상태로 기준 재설정 후 눈 감음/다시 뜸 문턱 확인 |
| 화면은 부드러운데 반응이 느림 | 화면 fps와 얼굴 추론 fps를 구분해 확인. 유화 해상도·추론 간격 점검 |
| 코드 변경이 안 보임 | 개발 서버는 HMR이 꺼져 있어 수동 새로고침. 빌드 화면은 재빌드 |
| 다른 PC에서 설정이 다름 | 빌드 화면은 브라우저·주소별 저장. 공용값은 `public/config.json`에 반영 후 재빌드 |
